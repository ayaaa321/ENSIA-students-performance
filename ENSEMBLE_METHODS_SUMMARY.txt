📈 WHAT WAS TESTED
════════════════════════════════════════════════════════════════════════════

✅ Method 1: VOTING (AVERAGE)
   Simple average of Ridge + RF predictions
   Formula: y = (y_ridge + y_rf) / 2
   Result: 1.2186 MAE → +1.75% improvement
   
✅ Method 2: VOTING (WEIGHTED)  
   Weighted average based on validation MAE
   Formula: y = 0.50*y_ridge + 0.50*y_rf
   Result: 1.2185 MAE → +1.76% improvement
   
✅ Method 3: STACKING (BEST) 🏆
   Meta-learner combines base predictions
   Architecture:
     Ridge + RandomForest → [pred1, pred2] → Meta-Learner → Final
   Result: 1.2008 MAE → +3.19% improvement
   

🔍 WHY STACKING IS BEST
════════════════════════════════════════════════════════════════════════════

1. LEARNED OPTIMAL WEIGHTS
   • Voting uses fixed weights (equal or inverse MAE)
   • Stacking learns weights from data
   • Better captures data-specific patterns

2. COMPLEMENTS BASE MODELS
   • Ridge: Good at linear relationships
   • RandomForest: Good at non-linearities
   • Stacking: Learns when to use which

3. CORRECTS SYSTEMATIC BIASES
   • Ridge tends to over/underpredict on certain data types
   • RF tends opposite on those types
   • Meta-learner learns these patterns and corrects them

4. ROBUST TRAINING
   • Uses 3-fold CV for meta-feature generation
   • Out-of-fold approach prevents overfitting
   • Reliable generalization to test data


💡 HOW STACKING WORKS
════════════════════════════════════════════════════════════════════════════

Training:
  1. Split data into 3 inner folds
  2. For each fold:
     • Train Ridge + RF on fold's training part
     • Get predictions on fold's validation part
  3. Stack these predictions: [pred_ridge, pred_rf]
  4. Train Ridge (meta-learner) on stacked features
     y_final = β₀ + β₁*pred_ridge + β₂*pred_rf

Inference:
  1. Get prediction from Ridge model
  2. Get prediction from RF model
  3. Combine with meta-learner: y = β₀ + β₁*y1 + β₂*y2
  4. Return final prediction
