2.1 MODEL CHARACTERISTICS
--------------------------

LINEAR REGRESSION (Baseline)
-----------------------------
Type: Ordinary Least Squares (OLS)
Parameters: None (no regularization)
Complexity: Low
Assumptions: Linear relationship, no multicollinearity
Training time: Fast

Strengths:
  + Simple and interpretable
  + Fast training and prediction
  + Good baseline for comparison

Weaknesses:
  - No regularization (prone to overfitting with correlated features)
  - Assumes strict linearity
  - Sensitive to outliers
  - Poor performance on this dataset


RIDGE REGRESSION (L2 Regularization)
-------------------------------------
Type: Linear model with L2 penalty
Parameters: alpha (regularization strength) = 10.0 or 100.0 (tuned via GridSearchCV)
Complexity: Low-Medium
Assumptions: Linear relationship, handles multicollinearity
Training time: Fast

Strengths:
  + Handles correlated features (20 one-hot encoded features)
  + Prevents overfitting via L2 penalty
  + Stable and robust predictions
  + Interpretable coefficients
  + Best performance on this dataset

Weaknesses:
  - Still assumes linearity
  - Doesn't capture complex interactions


RANDOM FOREST REGRESSOR (Ensemble)
-----------------------------------
Type: Ensemble of decision trees
Parameters: 
  - n_estimators: 100-200 (tuned)
  - max_depth: 5-20 (tuned)
  - max_features: sqrt or 0.5 (tuned)
  - min_samples_split: 2-5
  - min_samples_leaf: 1-2
Complexity: High
Assumptions: None (non-parametric)
Training time: Slow

Strengths:
  + Captures non-linear relationships
  + Handles feature interactions automatically
  + No assumptions about data distribution
  + Feature importance scores available
  + Robust to outliers

Weaknesses:
  - Overfits on small datasets (observed in this project)
  - Less interpretable (black box)
  - Requires more data than available (225 is small for RF)
  - Slower training and prediction

3.2 K-FOLD CROSS-VALIDATION APPROACH (5-FOLD)
----------------------------------------------

Structure:
----------
Total samples: 225 (all used)
Outer folds: 5 (for evaluation)
Inner folds: 5 (for hyperparameter tuning)
Training per fold: 180 samples (80%)
Test per fold: 45 samples (20%)

Process (Nested K-Fold):
------------------------
Outer loop (5 iterations):
  Split data into 180 train / 45 test
  Inner loop (5 iterations within each outer fold):
    GridSearchCV/RandomizedSearchCV with 5-fold CV
    Find best hyperparameters (alpha for Ridge, n_estimators/depth for RF)
  Train model on 180 samples with best hyperparameters
  Evaluate on 45 test samples
Aggregate: mean ± std across 5 outer folds

ADVANTAGES:
-----------
✓ Uses 100% of data (every sample tested once, trained on 4/5 times)
✓ Confidence intervals (mean ± std) for uncertainty quantification
✓ More stable estimates (5 independent evaluations)
✓ Larger test sets per fold (45 vs 2-32 in train/test split)
✓ Reduces variance from lucky/unlucky splits
✓ Better use of small datasets
✓ No data wasted on validation (nested CV handles tuning)

DISADVANTAGES:
--------------
✗ Computationally expensive (5x more training)
✗ Slower to execute
✗ More complex to implement

Results (Ridge Regression):
----------------------------
Overall: 1.2077 ± 0.1409 MAE
Per fold: [0.9596, 1.2378, 1.1799, 1.3847, 1.2767]
95% Confidence Interval: 1.07 to 1.35 MAE

Per-Cohort K-Fold Results:
1Y: 1.2235 MAE (45 test samples per fold)
2Y: 1.1406 MAE (45 test samples per fold)
3Y: 1.5056 MAE (45 test samples per fold)

Overall Assessment: 100% of metrics are reliable

4.1 NON-POOLED (PER-VERSION BASELINE)
--------------------------------------

Approach:
---------
Train separate Linear Regression model for EACH cohort independently:
- 1Y model: trained on 147 samples (1Y only)
- 2Y model: trained on 70 samples (2Y only)
- 3Y model: trained on 8 samples (3Y only)

Each model evaluated on its own cohort's test set.

Results (Linear Regression per-version):
=========================================
Cohort  Train_n  Test_n  Test_MAE  RMSE    Notes
------  -------  ------  --------  ----    -----
1Y      147      32      1.8763    2.2446  Adequate training data
2Y      70       16      1.1812    1.4814  Limited training data
3Y      8        2       0.8920    1.0293  VERY limited (unreliable)

ADVANTAGES:
-----------
✓ Model tailored to each cohort's specific patterns
✓ No assumptions about cross-cohort similarity

DISADVANTAGES:
--------------
✗ 3Y has only 8 training samples (severe underfitting risk)
✗ 2Y has only 70 samples (marginal for regression)
✗ No knowledge transfer between cohorts
✗ Cannot leverage 1Y's larger dataset to help 2Y/3Y
✗ High variance in predictions (small data)


4.2 POOLED TRAINING
-------------------

Approach:
---------
Train SINGLE model on COMBINED data from all cohorts:
- Total training: 225 samples (147 + 70 + 8)
- Same model predicts for all cohorts
- Evaluated separately on each cohort's test set

Assumption: Student performance patterns are similar across cohorts,
so 1Y/2Y/3Y can share knowledge.

Results (Ridge Regression pooled - train/test split):
======================================================
Cohort  Pooled_Test_MAE  Per-Version_MAE  Improvement  Pct_Gain
------  ---------------  ---------------  -----------  --------
1Y      1.2686           1.8763           -0.6077      -32.4% ✓
2Y      1.0555           1.1812           -0.1257      -10.6% ✓
3Y      0.4988           0.8920           -0.3932      -44.1% ✓

ADVANTAGES:
-----------
✓ 3Y benefits massively (8 samples → 225 pooled)
✓ Knowledge transfer: 1Y patterns help 2Y/3Y
✓ Better generalization across cohorts
✓ Single unified model (easier deployment)
✓ 10-44% improvement across all cohorts

DISADVANTAGES:
--------------
✗ Assumes cohorts are similar (valid in this case)
✗ May underperform if cohorts are very different
