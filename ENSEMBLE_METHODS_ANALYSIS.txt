METHODS TESTED
================================================================================

1. VOTING ENSEMBLE (AVERAGE)
═══════════════════════════════

Concept: Average predictions from two base models
Formula: y_pred = (y_ridge + y_rf) / 2

How it works:
  1. Train Ridge Regression on full training data
  2. Train RandomForest on full training data
  3. For new data: Get predictions from both models
  4. Average the two predictions

Results:
  MAE: 1.2186 ± 0.1025
  Improvement: +1.75% over Ridge
  
Why it helps:
  • Ridge captures linear relationships
  • RF captures non-linear patterns
  • Average balances both signals

Limitations:
  • Both models get equal weight
  • No learning from errors
  • Simple but not optimal


2. VOTING ENSEMBLE (WEIGHTED)
═════════════════════════════

Concept: Weighted average based on model performance
Formula: y_pred = α*y_ridge + β*y_rf
         where α + β = 1, based on validation MAE

How it works:
  1. Calculate each model's MAE on validation data
  2. Assign weights inversely proportional to MAE
  3. Better-performing model gets higher weight
  4. Ridge weight: 0.50 (1.2404 MAE)
  5. RF weight:   0.50 (1.2644 MAE)

Results:
  MAE: 1.2185 ± 0.1026
  Improvement: +1.76% over Ridge
  Weights: Ridge 0.50, RF 0.50
  
Why it helps:
  • Dynamic weighting based on performance
  • Better model contributes more
  • Still simple to implement

Note: Weights nearly equal because both models similar performance
      (hence minimal improvement over simple voting)


3. STACKING ENSEMBLE (META-LEARNER)
═══════════════════════════════════

Concept: Train meta-learner to combine base model predictions
Architecture:
  Level 0 (Base models): Ridge + RandomForest
  Level 1 (Meta-learner): Ridge learns optimal combination

How it works:
  1. Split training data using 3-fold cross-validation
  2. For each fold:
     a. Train Ridge + RF on training portion
     b. Get predictions on validation portion (out-of-fold)
     c. Stack these predictions as "meta-features"
  3. Train meta-learner Ridge on meta-features
  4. For inference:
     a. Get y_ridge from Ridge model
     b. Get y_rf from RF model
     c. Meta-learner: y_final = β₀ + β₁*y_ridge + β₂*y_rf

Results:
  MAE: 1.2008 ± 0.1139
  Improvement: +3.19% over Ridge
  
Why it helps:
  • Learns optimal weighting automatically
  • Considers non-linear combinations
  • Uses out-of-fold predictions (prevents overfitting)
  • Meta-learner sees where base models fail

Advantages over voting:
  • Learned weights (not fixed)
  • Potentially non-linear combinations
  • More data-driven approach

================================================================================
WHY STACKING OUTPERFORMS VOTING
================================================================================

1. LEARNED OPTIMAL WEIGHTS
   ────────────────────────
   Voting (weighted): Uses fixed weights from validation MAE
     Weight_Ridge = 0.50
     Weight_RF = 0.50
   
   Stacking: Learns weights from meta-training
     Coefficient_Ridge = β₁ (learned)
     Coefficient_RF = β₂ (learned)
     Intercept = β₀ (learned)
   
   Why better: Meta-learner discovers that base predictions need
               adjustment, not just weighted averaging

2. CAPTURES COMPLEMENTARY PATTERNS
   ──────────────────────────────
   Ridge strengths: Linear relationships (good for smooth trends)
   RF strengths: Non-linear patterns (good for complex interactions)
   
   Stacking learns:
   • When to trust Ridge more (linear trend data)
   • When to trust RF more (non-linear data)
   • How to combine them for optimal result
   
   Voting just averages: Misses data-specific insights

3. ADDRESSES BASE MODEL BLIND SPOTS
   ───────────────────────────────
   Voting assumes: Both models equally useful
   
   Stacking discovers:
   • Ridge tends to overpredict on certain data types
   • RF tends to underpredict on others
   • Meta-learner corrects these systematic biases
   
   Result: Predictions closer to actual values

4. USES OUT-OF-FOLD META-FEATURES
   ──────────────────────────────
   Method: 3-fold inner CV for meta-training
   
   Prevents overfitting because:
   • Meta-learner never sees same data used for base training
   • Similar to cross-validation principle
   • Reliable generalization to test data
   
   Result: Better test performance than training performance

IMPLEMENTATION DETAILS
================================================================================

STACKING ARCHITECTURE:
───────────────────────

Input: Student data (31 features)
  ↓
  ├─→ Ridge Model (α=10.0) ──→ Prediction_1
  │
  └─→ RandomForest Model ──→ Prediction_2
       (n_estimators=100, max_depth=10,
        max_features=0.5, min_samples_leaf=2)
  
Meta-Feature Layer: [Prediction_1, Prediction_2]
  ↓
Meta-Learner: Ridge (α=1.0)
  y_final = β₀ + β₁*Prediction_1 + β₂*Prediction_2
  ↓
Output: Final prediction


TRAINING PROCEDURE:
────────────────

Phase 1: Build Meta-Training Data
  1. Use 3-fold CV on full training data
  2. For each of 3 folds:
     a. Train Ridge on fold's training portion
     b. Train RF on fold's training portion
     c. Get predictions on fold's validation portion
     d. Save these predictions
  3. Collect all out-of-fold predictions
     → Meta-training set: [y_ridge_oof, y_rf_oof]

Phase 2: Train Meta-Learner
  1. Stack Ridge and RF predictions as 2-column matrix
  2. Train Ridge on this matrix to predict y_true
  3. Meta-learner learns coefficients β₀, β₁, β₂

Phase 3: Evaluation
  1. For test data:
     a. Get Ridge prediction
     b. Get RF prediction
     c. Use meta-learner to combine → final prediction
  2. Calculate MAE, RMSE, R²


HYPERPARAMETERS:
─────────────────

Ridge (base learner):
  alpha = 10.0 (tuned via GridSearchCV)
  
RandomForest (base learner):
  n_estimators = 100
